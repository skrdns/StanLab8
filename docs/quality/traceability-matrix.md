# Traceability Matrix

**Версія:** 1.0  
**Дата:** 2025  
**Джерело вимог:** [SSD](../architecture/SSD.md)  
**Джерело тест-кейсів:** [Test Strategy](test-strategy.md)

> Цей документ є Single Source of Truth для відповідності між вимогами та тестами.

---

## Матриця відповідності

| Вимога (FR) | Опис вимоги | Тест-кейс (TC) | Рівень тесту | Статус |
|-------------|-------------|----------------|--------------|--------|
| FR-01 | Реєстрація та авторизація | TC-01 | Integration | ✅ Покрито |
| FR-02 | Створення замовлення | TC-02 | Integration | ✅ Покрито |
| FR-03 | Редагування замовлення | TC-03 | Integration | ✅ Покрито |
| FR-04 | Скасування замовлення | TC-04 | Integration | ✅ Покрито |
| FR-05 | Перегляд історії замовлень | TC-05 | Integration | ✅ Покрито |
| FR-06 | Адміністративне управління | TC-06 | Integration | ✅ Покрито |

---

## Правила оновлення

- При додаванні нової вимоги в [SSD](../architecture/SSD.md) — додати рядок у цю матрицю
- При додаванні нового тест-кейсу — прив'язати до існуючого FR-ID
- Вимога без тест-кейсу вважається **не покритою** і блокує реліз
