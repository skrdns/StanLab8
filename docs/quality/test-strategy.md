# Test Strategy

**Версія:** 1.0  
**Дата:** 2025  
**Джерело вимог:** [SSD](../architecture/SSD.md)

> Усі тест-кейси прив'язані до ідентифікаторів вимог з SSD.
> Повна матриця відповідності — у [Traceability Matrix](traceability-matrix.md).

---

## 1. Рівні тестування

### Unit тести
- Ізольована перевірка окремих функцій backend
- Інструмент: Jest (Node.js) / pytest (Python)
- Покриття: мінімум 80% для бізнес-логіки

### Integration тести
- Перевірка взаємодії backend ↔ database
- Перевірка REST API endpoints
- Інструмент: Supertest / httpx

### UI тести (E2E)
- End-to-end тестування через браузер
- Інструмент: Playwright
- Сценарії: реєстрація → створення замовлення → скасування

### Навантажувальне тестування
- Ціль: до 500 запитів/хв без деградації
- Час відповіді: до 300 мс (відповідно до [SSD](../architecture/SSD.md))
- Інструмент: k6

## 3. Критерії готовності (Definition of Done)

- Усі тест-кейси з Traceability Matrix виконані
- Покриття unit тестами ≥ 80%
- Навантажувальне тестування пройдено без перевищення 300 мс
- Жодного відкритого критичного або високого дефекту
