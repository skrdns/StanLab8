# SSD — System Specification Document

**Версія:** 1.0  
**Дата:** 2025  
**Статус:** Актуальний

> ⚠️ Цей документ є Single Source of Truth для всіх функціональних вимог.
> Усі інші документи посилаються на ідентифікатори FR-XX з цього файлу.

---

## 1. Призначення системи

Система забезпечує автоматизацію процесу управління замовленнями користувачів.
Вона дозволяє клієнтам оформлювати, редагувати та відстежувати замовлення,
а адміністраторам — керувати ними та переглядати аналітику.

Система працює через веб-інтерфейс (UI) та REST API з JWT-авторизацією.

---

## 2. Цільова аудиторія

| Роль | Опис |
|------|------|
| Клієнт | Оформлює та відстежує замовлення |
| Адміністратор | Керує замовленнями, переглядає аналітику |
| Розробник | Розробляє та підтримує систему |
| Тестувальник | Перевіряє функціональність системи |

| ID | Вимога | Пріоритет | Актор |

---

## 4. Нефункціональні вимоги

- **Продуктивність:** до 500 запитів/хв
- **Час відповіді:** до 300 мс на запит
- **Доступність:** 99.9%
- **Безпека:** HTTPS, JWT-авторизація, розмежування прав доступу

---

## 5. Обмеження та припущення

- Система працює через інтернет
- Використовується одна реляційна база даних
- Максимальне навантаження обмежене серверними ресурсами
